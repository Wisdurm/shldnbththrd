# shldnbththrd

**shldnbththrd** is a super simple modal vector animation program that was made
in around 4 hours to prove it should not be that hard for someone else to make a 
proper Pivot animator-like tool for Linux.

This program offers the bare minimum for making animations using just straight lines,
with the most mindblowing, awe-inspiring feature being that you can rotate points around
each other (Wow!).
